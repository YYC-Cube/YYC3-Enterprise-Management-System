|序号|检查项|验收标准|
|----|----|----|

### 阶段4：单模块自测（1天｜P0 单元+功能自测）

1. **后端自测**

- 单接口Postman逐个调用：正常参数/空参数/越权token/超限频次，校验返回码符合规范
- 手动构造弱网、AI接口超时，验证自动降级返回默认策略

1. **前端自测**

- PC/移动端不同分辨率：大屏自动展开胶囊、小屏收缩圆点
- 切换系统时间（9点/22点），验证bizMode自动切换operate/manage
- 语音输入：「打开NAS故障排查」→中台分发→AI自动生成任务导航

1. **异常自测**：关闭后端服务→前端读取缓存兜底配置，导航不崩溃

### 阶段5：前后端联调（1天｜P0）

|联调场景|验收结果|
|----|----|
|场景1：常规工作时段PC访问|自动启用float+gen组合，侧边磁吸悬浮常驻，AI可自然语言生成导航|
|场景2：夜间非工作时段|默认经管类导航权重前置，资质相关入口优先展示|
|场景3：弱网模拟(Chrome限流500kb/s)|禁用云端AI生成，仅本地端侧生成导航|
|场景4：语音指令打开硬件AR预览|移动端拉起AR锚点导航，PC弹窗预览模型|

### 阶段6：灰度上线&线上观测（3天｜P0灰度20%用户）

1. 灰度规则：白名单+随机20%登录用户开启混合导航，剩余80%沿用原有分离式导航
2. 线上观测指标看板（监控四项核心数据）
   - 导航点击率、误触率（对标基线：点击率+25%、误触<基线40%）
   - 指令成功率（文本/语音/手势三类交互成功率≥90%）
   - 前端报错率<0.1%、后端接口5xx错误=0
3. 异常熔断：灰度期间出现指标大幅恶化，一键关闭混合导航开关，回滚为原有独立导航

### 阶段7：全量发布+复盘优化（1天｜全量上线+闭环复盘）

1. 灰度数据达标后全量放开所有用户；

   - 用户反馈问题录入需求池，优化Prompt/调度规则；
3. 数据回流：日度统计数据自动优化导航组件权重，完成**数据→产品优化闭环**

## 第二章：混合导航全链路端到端教科书实操示例（YYC³真实业务演示链路）
>
> 场景：工作日14:00（工作时段、PC宽带高网速、管理员admin角色、当前在NAS运维页面），用户**语音指令：帮我排查NAS登录缓存故障**
>
### 全链路分步拆解（从用户操作→前端→混合中台→悬浮+AI双导航生成→交互埋点→数据入库→次日优化闭环）

#### Step1：前端采集多源信息（感知层）

1. WebSpeech捕获语音文本：`帮我排查NAS登录缓存故障`，cmdType=voice；
2. 前端同步上报设备信息：deviceWidth=1920、deviceType=desktop、当前路由`/nas/dashboard`；
3. 前端定时拉取`/hybrid/context`：

```json
{
  "bizMode":"operate",
  "timeTag":"work",
  "netLevel":"high",
  "enableRule":["float+gen"],
  "arEnable":false,
  "threeEnable":true
}
```

> 中台判定：启用「悬浮+AI生成」组合模式。

#### Step2：指令送入混合中台调度接口`POST /api/v1/nav/hybrid/command`

后端Service调度引擎解析：

1. 关键词`NAS、缓存故障`→判定运维任务，路由分发两条指令：
   - 指令A：推送任务至**悬浮任务链导航**；
   - 指令B：推送自然语言至**AI生成导航接口`/generate/by-prompt`**。

#### Step3：底层两个导航模块分别生成数据

1. **悬浮导航侧**：后端写入nav_task任务记录，taskId自动生成T2026xxx，progress=0，步骤数组：日志→配置→重载→重启；前端悬浮任务条新增该任务卡片；
2. **AI生成侧**：大模型按照Schema输出标准化临时导航navId=GNxxxx，四步按钮/卡片导航，写入nav_gen_temp并设置过期3600s；前端动态渲染临时AI导航面板。

#### Step4：用户交互操作+全链路自动埋点

用户点击「缓存日志解析」：

1. 前端跳转`/nas/log/cache`，自动调用`PATCH /float/task/progress`，对应步骤done:true、progress更新25；
2. 同步埋点上报`/stat/track`：navType=hybrid、operate=click、itemId=T2026xxx，屏幕坐标&停留时长入库nav_stat_track。

#### Step5：任务完结闭环

用户全部步骤操作完毕→前端调用`DELETE /generate/GNxxxx`销毁临时AI导航；悬浮任务自动标记finish=true，归档历史任务。

#### Step6：次日大数据优化闭环（凌晨定时任务）

1. 统计该类指令点击率高→后端自动在组件元数据中提升NAS相关导航weight权重；
2. 若多条用户反馈该导航缺少NFS排查→录入feedback表，迭代优化AI导航Prompt模板。

## 第三章：工程&产品思维延伸逻辑培养方法（导航领域通用学习方法论，从单点开发→架构全局→产品数据化）

### 一、四层思维递进路线（从写代码→懂设计→懂业务→懂数据驱动）

#### 第一层：代码落地思维（初学阶段：模块怎么写、接口怎么调）

**训练方法：单点拆解复盘**

1. 每次写完一个组件/接口，自问3个问题：
   ①这段逻辑如果换移动端怎么改？②异常场景（断网/报错）有没有兜底？③能否复用至另一个业务（运维→经管）？
2. 强制习惯：新增功能前先画简易数据流图（输入→处理→输出），再写代码。
**举例**：混合指令分发函数，写完后思考：后续新增手势/眼动追踪指令，代码如何做到不改动原有逻辑即可扩展（开闭原则）→抽离策略工厂模式。

#### 第二层：模块化架构思维（进阶：分层解耦、依赖设计）

**核心训练：依赖倒置、分层隔离**

1. 固定拆解公式：**感知层→调度层→渲染层→闭环层**，任何新导航功能都套四层拆分；
2. 刻意练习：混合中台不直接依赖悬浮/生成的具体实现，只依赖接口规范，底层导航改版不改动中台代码；
3. 延伸练习：假设未来新增第四种导航（AI侧边弹窗导航），现有混合调度架构能否无缝接入？不能就优化抽象。

#### 第三层：产品业务思维（高阶：从用户视角设计策略，而非纯技术实现）

**训练：业务场景穷举法**

1. 拆分YYC³两大业务：运维（硬件故障、服务器配置）、经管（资质、商标备案），分别罗列20个高频用户场景，逐个设计最优组合导航策略；
2. 逆向思考：用户为什么不用新导航？是交互繁琐还是生成内容不准？从业务痛点反向优化调度规则。

> 例：资质办理用户低频使用服务器导航→经管模式自动降低运维导航权重。

#### 第四层：数据驱动闭环思维（专家级：用数据迭代产品，自动化优化）

**训练：指标锚定法**

1. 先定核心指标（点击率、误触率、任务完成耗时），所有功能设计围绕指标提升；
2. 养成习惯：每上线一个功能，配套埋点方案+统计落地规则，实现「上线→采集数据→分析→迭代优化」闭环；
3. 延伸：把导航优化思路平移到其他系统：如后台表单、设备监控页面，复用数据闭环逻辑。

### 二、横向跨领域思维延伸（导航→全项目通用能力）

1. **AI领域延伸**：从生成导航Prompt优化→拓展整个项目AI接口设计规范、端云双推理降级方案；
2. **大数据延伸**：从导航埋点→全平台用户行为埋点体系搭建；
3. **前端架构延伸**：从Zustand多切片状态管理→整站状态分层设计规范；
4. **后端架构延伸**：从导航中台调度→项目全局统一指令中台设计。

### 三、日常刻意练习小任务（每日10分钟，长期构建系统化思维）

1. **场景改造练习**：每周任选1个现有导航策略，假设设备换成AR眼镜/车载大屏，重新设计组合导航方案；
2. **故障推演练习**：模拟3种线上极端故障（AI服务宕机、Redis崩了、前端组件渲染报错），手写全套降级修复方案；
3. **竞品对标练习**：参考鸿蒙/生成式UI产品导航逻辑，提炼可用规则落地到YYC³，对比数据变化。

# @yyc3/effects 极简上手模板

直接复制粘贴即可运行，分**零依赖基础特效**和**3D特效**两套模板

---

## 一、先执行安装命令

```bash
# npm安装
npm i @yyc3/effects react react-dom

# pnpm安装（推荐）
pnpm add @yyc3/effects react react-dom
```

---

## 二、零依赖特效模板（直接用，无额外依赖）

赛博朋克风格：故障文字 + 霓虹卡片

```jsx
import React from 'react';
import { NeonCard, GlitchText } from '@yyc3/effects';

function App() {
  return (
    <div style={{ padding: '50px', background: '#000' }}>
      {/* 故障文字特效 */}
      <GlitchText text="YYC3 特效库" fontSize={40} color="#0ff" />

      {/* 霓虹卡片 */}
      <NeonCard
        theme="cyberpunk"
        title="开箱即用"
        content="React 赛博朋克特效组件"
        style={{ marginTop: 20, width: 320 }}
      />
    </div>
  );
}

export default App;
```
